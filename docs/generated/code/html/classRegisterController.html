Detailed Description

Registration controller for research staff user.

Handles user registration for different roles (student, professor, committee leader, research_staff) within the research staff system. Each role is associated with a specific profile model.

This controller uses Laravel's RegistersUsers trait but customizes validation, creation, and post-registration behavior to fit the application's requirements.
